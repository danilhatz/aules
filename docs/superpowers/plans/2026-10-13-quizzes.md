# Quizzes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let the student take simple Aules quizzes (multiple choice, true/false, short answer, numeric) in the app and review finished attempts, while never offering Start for a quiz the app cannot finish.

**Architecture:** DOM-free logic modules (`quiz.js` parsing and the start check, `qhtml.js` strict question-markup sanitizer and answer serialisation, `attemptstore.js` local answer protection) are unit-tested against sample Moodle JSON/markup. `ui/quiz.js` and `ui/attempt.js` render the screens and talk to the app only through injected callbacks. `app.js` adds three routes with the existing patterns: saved-data-first, parallel requests, locked until verified fresh, epoch guards, and writes that are never replayed.

**Tech Stack:** Same as before (browser ES modules, Fetch, localStorage; dev: Node >= 20 `node:test`, `jsdom`). No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-13-quizzes-design.md` (extends the earlier specs in the same folder)

## Global Constraints

- Vanilla ES modules, **no build step**, no new dependencies. CSP in `index.html` unchanged.
- Site base `https://aules.edu.gva.es/fpa`; token appended only to `.../fpa/webservice/pluginfile.php/...` URLs via `withToken`.
- **Write-safety (binding, same as assignments):** nothing is written without an explicit tap; **Start** and **Finish** go through an in-page confirm; single-flight; **no automatic retry or replay of any write**; an expired token during a write renews the session but asks the user to tap again; an unknown outcome (network error or `badresponse` after a write was sent) -> reload and "could not confirm", never assume; every write step is refused after sign-out and its result and flash dropped; the answer area locks while a write is in flight; nothing is sent automatically when the timer ends.
- **Never offer Start for a quiz the app cannot finish:** Start requires fresh data and all of: no unsupported access rule, only supported question types, no pre-flight check, no blocking reason, `canattempt`, no in-progress/overdue attempt. A saved copy of the quiz screen never offers Start.
- Supported question types: `multichoice`, `truefalse`, `shortanswer`, `numerical` (plus `description`). Allowed access rules: `quizaccess_openclosedate`, `quizaccess_numattempts`, `quizaccess_timelimit`, `quizaccess_delaybetweenattempts`.
- Question markup goes only through `sanitizeQuestionHtml`; answer field names must match `^q\d+:\d+_:?[A-Za-z0-9_-]+$` and never end in `:flagged`; flag controls are removed and never sent. Moodle plain strings render via `textContent`/`h()`.
- Sign-out clears the token, saved login, caches, drafts, local quiz answers (`aules.attempt.*`) and flags; in-flight results after sign-out are dropped (epoch guard).
- Performance rules from the perf round apply to new screens: saved data first where safe, independent requests in parallel, no heavy call on the critical path.
- App files are served cache-first: this plan bumps `VERSION` in `sw.js` to `v5` in Task 1 and the release task records the new hash with `npm run lock-shell`.
- Tests use dummy values only (user number `10000001`); **no real credentials anywhere**. The assistant never logs into the live site and never runs write calls against it.
- Touch targets >= 44px, body 17px, light/dark mode, phone one-pane / iPad two-pane preserved. `node --test` stays green after every task; each new `src/` module is added to the `sw.js` SHELL in the task that creates it; nothing is pushed or published without the user's explicit approval.

## Review Focus

1. **Start eligibility:** unsupported rules, unsupported question types, pre-flight required, blocking reasons, `canattempt` false, in-progress and overdue attempts, and any failed/missing check (`unknown`) must all hide Start; a saved (not fresh) screen and the offline view never offer it. (Tasks 2, 5, 8)
2. **Hostile markup:** foreign field names, fake hidden fields, `<form action>`, file/password inputs, `onclick`/`style`, `javascript:`/`data:` URLs, DOM-clobbering ids, foreign `label for`, class injection. (Task 3)
3. **Answer serialisation equals a browser form:** radios/checkboxes only when checked, hidden always, selects/text/textarea values, disabled skipped, flags excluded, no foreign names; snapshot/restore round-trips including *unchecking*. (Task 3)
4. **Write safety for Start, page change, Save and Finish:** double-tap, confirm, no replay, unconfirmed outcome, sign-out mid-write, expired token, timer lock with no auto-send. (Tasks 5, 6, 8)
5. **Local answer protection and navigation:** snapshots are per attempt and page, reapplied only to the matching page, cleared at finish and sign-out; sequential quizzes hide Previous; the hash-based page navigation survives reloads. (Tasks 4, 6, 8)

  ws(token, 'mod_quiz_get_quizzes_by_courses', { 'courseids[0]': courseId }, fetchImpl);

export const getAttemptAccess = (token, quizId, attemptId = 0, { fetchImpl } = {}) =>

  ws(token, 'mod_quiz_get_quiz_required_qtypes', { quizid: quizId }, fetchImpl);

export const getUserAttempts = (token, quizId, { fetchImpl } = {}) =>
  ws(token, 'mod_quiz_get_user_attempts', { quizid: quizId, status: 'all', includepreviews: 0 }, fetchImpl);

export const getBestGrade = (token, quizId, { fetchImpl } = {}) =>

export const getAttemptData = (token, attemptId, page, { fetchImpl } = {}) =>
  ws(token, 'mod_quiz_get_attempt_data', { attemptid: attemptId, page }, fetchImpl);

export const getAttemptSummary = (token, attemptId, { fetchImpl } = {}) =>
  ws(token, 'mod_quiz_get_attempt_summary', { attemptid: attemptId }, fetchImpl);

export const getAttemptReview = (token, attemptId, { fetchImpl } = {}) =>
  ws(token, 'mod_quiz_get_attempt_review', { attemptid: attemptId, page: -1 }, fetchImpl);

function throwOnResultWarnings(result) {
  const w = result && Array.isArray(result.warnings) && result.warnings[0];
  if (w) throw new MoodleError(w.warningcode || 'warning', w.message || w.warningcode || 'warning');
}

export async function startAttempt(token, quizId, { fetchImpl } = {}) {
  const r = await ws(token, 'mod_quiz_start_attempt', { quizid: quizId }, fetchImpl);
  throwOnResultWarnings(r);
  if (!r || !r.attempt) throw new MoodleError('warning');
  return r;
}

export async function saveAttempt(token, attemptId, data, { fetchImpl } = {}) {
  const r = await ws(token, 'mod_quiz_save_attempt', { attemptid: attemptId, ...flatten({ data }) }, fetchImpl);
  throwOnResultWarnings(r);
  if (!r || r.status !== true) throw new MoodleError('warning');
  return r;
}

export async function processAttempt(token, attemptId, data, { finish = false, timeup = false, fetchImpl } = {}) {
  const r = await ws(token, 'mod_quiz_process_attempt', {
    attemptid: attemptId, finishattempt: finish ? 1 : 0, timeup: timeup ? 1 : 0, ...flatten({ data }),
  }, fetchImpl);
  throwOnResultWarnings(r);
  return r;
}

const num = (v) => (Number.isFinite(Number(v)) ? Number(v) : 0);
const list = (v) => (Array.isArray(v) ? v : []);

export const SUPPORTED_QTYPES = new Set(['multichoice', 'truefalse', 'shortanswer', 'numerical', 'description']);
const ALLOWED_RULES = new Set(['quizaccess_openclosedate', 'quizaccess_numattempts', 'quizaccess_timelimit', 'quizaccess_delaybetweenattempts']);
const STATES = new Set(['inprogress', 'overdue', 'finished', 'abandoned']);

export function parseQuiz(raw) {
  const r = raw || {};
  return {
    id: r.id,
    cmid: r.coursemodule,
    name: r.name || '',
    introHtml: r.intro || '',
    timeOpen: num(r.timeopen),
    timeClose: num(r.timeclose),
    timeLimit: num(r.timelimit),
    attemptsAllowed: num(r.attempts),
    gradeMethod: num(r.grademethod),
    maxGrade: num(r.grade),
    sumGrades: num(r.sumgrades),
    sequential: r.navmethod === 'sequential',
  };
}

export function parseAttempts(raw) {
  return list(raw && raw.attempts)
    .filter((a) => a && !a.preview)
    .map((a) => ({
      id: a.id,
      number: num(a.attempt),
      state: STATES.has(a.state) ? a.state : 'unknown',
      timeStart: num(a.timestart),
      timeFinish: num(a.timefinish),
      sumGrades: a.sumgrades == null ? null : num(a.sumgrades),
      currentPage: num(a.currentpage),
    }))
    .sort((a, b) => a.number - b.number);
}

export function parseBestGrade(raw) {
  const has = Boolean(raw && raw.hasgrade);
  return { has, grade: has && Number.isFinite(Number(raw.grade)) ? Number(raw.grade) : null };
}

export function attemptGrade(attempt, quiz) {
  if (attempt.state !== 'finished' || attempt.sumGrades === null || !quiz.sumGrades) return null;
  return Math.round(((attempt.sumGrades * quiz.maxGrade) / quiz.sumGrades) * 100) / 100;
}

const strings = (v) => list(v).filter((s) => typeof s === 'string' && s.trim() !== '');

// Decides what the quiz screen may offer. Anything uncertain means "do not start".
export function startCheck({ access, qtypes, attemptAccess, attempts }) {
  const base = { canStart: false, attemptId: null, messages: [], unsupportedTypes: [], unsupportedRules: [], preflight: false };
  if (!access || !qtypes || !attemptAccess || !attempts) return { ...base, mode: 'unknown' };
  const unsupportedRules = list(access.activerulenames).filter((n) => !ALLOWED_RULES.has(n));
  const unsupportedTypes = list(qtypes.questiontypes).filter((t) => !SUPPORTED_QTYPES.has(t));
  const preflight = attemptAccess.ispreflightcheckrequired === true;
  if (unsupportedRules.length || unsupportedTypes.length || preflight) {
    return { ...base, mode: 'unsupported', unsupportedRules, unsupportedTypes, preflight };
  }
  if (attempts.some((a) => a.state === 'overdue')) return { ...base, mode: 'overdue' };
  const running = attempts.find((a) => a.state === 'inprogress');
  if (running) return { ...base, mode: 'continue', attemptId: running.id };
  if (access.canattempt !== true) return { ...base, mode: 'blocked', messages: strings(access.preventaccessreasons) };
  const reasons = strings(attemptAccess.preventnewattemptreasons);
  if (reasons.length) return { ...base, mode: 'blocked', messages: reasons };
  return { ...base, mode: 'start', canStart: true };
}

export function formatTimeLeft(seconds) {
  const s = Math.max(0, Math.floor(seconds));
  const h = Math.floor(s / 3600);
  const m = Math.floor((s % 3600) / 60);
  const sec = String(s % 60).padStart(2, '0');
  return h > 0 ? `${h}:${String(m).padStart(2, '0')}:${sec}` : `${m}:${sec}`;
}

const NAME = /^q\d+:\d+_:?[A-Za-z0-9_-]+$/;
const ID = /^q\d+:\d+_[A-Za-z0-9:_-]+$/;
const isFlag = (n) => /:flagged$/.test(n);
export const isValidFieldName = (n) => typeof n === 'string' && NAME.test(n) && !isFlag(n);

const DROP = new Set(['script', 'style', 'iframe', 'object', 'embed', 'svg', 'math', 'form', 'link', 'meta', 'base', 'noscript', 'template', 'audio', 'video', 'button', 'canvas']);
const KEEP = new Set(['div', 'span', 'p', 'br', 'b', 'strong', 'i', 'em', 'sub', 'sup', 'ul', 'ol', 'li', 'table', 'thead', 'tbody', 'tr', 'th', 'td', 'a', 'img', 'label', 'fieldset', 'legend', 'input', 'select', 'option', 'textarea', 'h3', 'h4', 'h5', 'h6', 'pre', 'code']);
const CLASSES = new Set(['que', 'correct', 'incorrect', 'partiallycorrect', 'state', 'grade', 'qtext', 'answer', 'rightanswer', 'specificfeedback', 'generalfeedback', 'outcome', 'feedback', 'prompt', 'ablock', 'formulation', 'content', 'info', 'no', 'qno', 'multichoice', 'truefalse', 'shortanswer', 'numerical', 'description']);
const INPUT_TYPES = new Set(['radio', 'checkbox', 'text', 'hidden']);

function safeLink(url, imageOnly) {
  try {
    const p = new URL(url, 'https://base.invalid').protocol;
    return p === 'http:' || p === 'https:' || (!imageOnly && p === 'mailto:');
  } catch {
    return false;
  }
}

function keepOnly(el, allowed) {
  for (const a of Array.from(el.attributes)) if (!allowed.includes(a.name)) el.removeAttribute(a.name);
}

function filterClass(el) {
  const kept = (el.getAttribute('class') || '').split(/\s+/).filter((t) => CLASSES.has(t));
  if (kept.length) el.setAttribute('class', kept.join(' '));
  else el.removeAttribute('class');
}

// Returns false when the element must be removed.
function cleanElement(el, tag, ctx) {
  filterClass(el);
  if (el.classList.contains('questionflag')) return false;
  switch (tag) {
    case 'input': {
      const type = (el.getAttribute('type') || 'text').toLowerCase();
      if (!INPUT_TYPES.has(type) || !isValidFieldName(el.getAttribute('name'))) return false;
      if (el.hasAttribute('id') && !ID.test(el.getAttribute('id'))) el.removeAttribute('id');
      keepOnly(el, ['type', 'name', 'value', 'id', 'checked', 'disabled', 'readonly', 'size', 'maxlength', 'inputmode', 'class']);
      el.setAttribute('type', type);
      if (!ctx.interactive) el.setAttribute('disabled', '');
      return true;
    }
    case 'textarea':
    case 'select': {
      if (!isValidFieldName(el.getAttribute('name'))) return false;
      if (el.hasAttribute('id') && !ID.test(el.getAttribute('id'))) el.removeAttribute('id');
      keepOnly(el, ['name', 'id', 'rows', 'cols', 'disabled', 'readonly', 'class']);
      if (!ctx.interactive) el.setAttribute('disabled', '');
      return true;
    }
    case 'option':
      keepOnly(el, ['value', 'selected']);
      return true;
    case 'label': {
      const f = el.getAttribute('for');
      keepOnly(el, ['for', 'class']);
      if (f && !ID.test(f)) el.removeAttribute('for');
      return true;
    }
    case 'a': {
      const href = el.getAttribute('href');
      keepOnly(el, ['href', 'title', 'class']);
      if (href && safeLink(href, false)) {
        el.setAttribute('href', ctx.rewriteUrl ? ctx.rewriteUrl(href) : href);
        el.setAttribute('target', '_blank');
        el.setAttribute('rel', 'noopener noreferrer');
      } else {
        el.removeAttribute('href');
      }
      return true;
    }
    case 'img': {
      const src = el.getAttribute('src');
      if (!src || !safeLink(src, true)) return false;
      keepOnly(el, ['src', 'alt', 'width', 'height', 'class']);
      el.setAttribute('src', ctx.rewriteUrl ? ctx.rewriteUrl(src) : src);
      return true;
    }
    default:
      keepOnly(el, ['class', 'colspan', 'rowspan']);
      return true;
  }
}

function walk(node, ctx) {
  for (const child of Array.from(node.childNodes)) {
    if (child.nodeType === 3) continue;
    if (child.nodeType !== 1) { child.remove(); continue; }
    const tag = child.localName;
    if (DROP.has(tag)) { child.remove(); continue; }
    if (!KEEP.has(tag)) {
      walk(child, ctx);
      while (child.firstChild) node.insertBefore(child.firstChild, child);
      child.remove();
      continue;
    }
    if (!cleanElement(child, tag, ctx)) { child.remove(); continue; }
    walk(child, ctx);
  }
}

export function sanitizeQuestionHtml(html, { rewriteUrl, interactive = true, DOMParserCtor } = {}) {
  const Parser = DOMParserCtor || globalThis.DOMParser;
  const doc = new Parser().parseFromString(String(html || ''), 'text/html');
  walk(doc.body, { rewriteUrl, interactive });
  return doc.body.innerHTML;
}

const controls = (container) => Array.from(container.querySelectorAll('input, select, textarea'));

// Same as submitting the web form: hidden always, radio/checkbox only when checked, enabled controls only.
export function collectAnswers(container) {
  const out = [];
  for (const el of controls(container)) {
    const name = el.getAttribute('name');
    if (!isValidFieldName(name) || el.disabled) continue;
    if (el.localName === 'input') {
      const type = el.type;
      if (type === 'radio' || type === 'checkbox') {
        if (el.checked) out.push({ name, value: el.value });
      } else if (type === 'hidden' || type === 'text') {
        out.push({ name, value: el.value });
      }
    } else {
      out.push({ name, value: el.value });
    }
  }
  return out;
}

export function snapshotAnswers(container) {
  const t = {};
  const c = {};
  for (const el of controls(container)) {
    const name = el.getAttribute('name');
    if (!isValidFieldName(name) || el.disabled) continue;
    if (el.localName === 'input' && (el.type === 'radio' || el.type === 'checkbox')) c[`${name}|${el.value}`] = el.checked;
    else if (!(el.localName === 'input' && el.type === 'hidden')) t[name] = el.value;
  }
  return { t, c };
}

export function restoreSnapshot(container, snapshot) {
  if (!snapshot || typeof snapshot !== 'object') return;
  const t = snapshot.t || {};
  const c = snapshot.c || {};
  for (const el of controls(container)) {
    const name = el.getAttribute('name');
    if (!isValidFieldName(name) || el.disabled) continue;
    if (el.localName === 'input' && (el.type === 'radio' || el.type === 'checkbox')) {
      const key = `${name}|${el.value}`;
      if (key in c) el.checked = Boolean(c[key]);
    } else if (!(el.localName === 'input' && el.type === 'hidden') && name in t) {
      el.value = String(t[name]);
    }
  }
}

const P = 'aules.attempt.';
const INDEX = 'aules.attempts.__index';

export function createAttemptStore(storage) {
  const readIndex = () => {
    try { return JSON.parse(storage.getItem(INDEX)) || []; } catch { return []; }
  };
  const read = (id) => {
    try {
      const v = JSON.parse(storage.getItem(P + id));
      return v && typeof v.pages === 'object' && v.pages ? v : null;
    } catch { return null; }
  };
  return {
    get(attemptId, page) {
      const v = read(attemptId);
      return v && v.pages[String(page)] ? v.pages[String(page)] : null;
    },
    set(attemptId, page, snapshot) {
      try {
        const key = String(attemptId);
        const idx = readIndex();
        if (!idx.includes(key)) storage.setItem(INDEX, JSON.stringify([...idx, key])); // index first: no orphans
        const current = read(key) || { pages: {} };
        current.pages[String(page)] = snapshot;
        storage.setItem(P + key, JSON.stringify({ pages: current.pages, savedAt: Date.now() }));
      } catch { /* best effort */ }
    },
    remove(attemptId) {
      try { storage.removeItem(P + attemptId); } catch { /* best effort */ }
    },
    clear() {
      try {
        for (const id of readIndex()) storage.removeItem(P + id);
        storage.removeItem(INDEX);
      } catch { /* best effort */ }
    },
  };
}

const defaultClock = {
  now: () => Math.floor(Date.now() / 1000),
  every: (fn) => setInterval(fn, 1000),
  stop: (handle) => clearInterval(handle),
};

function errorText(err) {
  const base = describeError(err);
  const detail = err && err.message && err.message !== err.code && !S.errors[err.code] ? ` ${err.message}` : '';
  return base + detail;
}

const backLink = (p) => h('a', { class: 'back', href: `#/course/${p.courseId}/quiz/${p.cmid}` }, '‹ ', S.backToQuiz);

export function renderAttempt(p) {
  const head = h('header', { class: 'bar' }, backLink(p), h('h2', {}, p.quiz.name));
  if (p.questions.some((q) => !SUPPORTED_QTYPES.has(q.type))) {
    return h('article', { class: 'course attempt' }, head,
      h('div', { class: 'note-box' }, h('p', { class: 'note' }, S.attemptUnsupported),
        h('a', { class: 'btn secondary link-btn', href: p.openUrl, target: '_blank', rel: 'noopener noreferrer' }, S.openInAules)));
  }
  const clock = p.clock || defaultClock;
  const rewriteUrl = (u) => withToken(u, p.token);

  const container = h('div', { class: 'questions' });
  for (const q of p.questions) {
    const sec = h('section', { class: 'question', 'data-slot': String(q.slot) });
    sec.innerHTML = sanitizeQuestionHtml(q.html, { rewriteUrl, interactive: true });
    container.append(sec);
  }
  if (p.snapshot) restoreSnapshot(container, p.snapshot);
  const notify = () => p.onSnapshot(snapshotAnswers(container));
  container.addEventListener('input', notify);
  container.addEventListener('change', notify);

  let busy = false;
  let timeUp = false;
  const msg = h('p', { class: 'form-msg', role: 'alert' }, '');
  const say = (t) => { msg.textContent = t; };
  const fields = h('fieldset', { class: 'answer-fields' }, container);
  const buttons = [];
  const setBusy = (b) => { busy = b; fields.disabled = b || timeUp; for (const x of buttons) x.disabled = b; };
  const answers = () => collectAnswers(container);
  const run = async (fn, onOk) => {
    if (busy) return;
    setBusy(true);
    say('');
    try {
      onOk(await fn());
    } catch (err) {
      if (err && err.code === 'signedout') return;
      if (err && err.code === 'unconfirmed') { p.onDone('unknown'); return; }
      say(errorText(err));
      setBusy(false);
    }
  };
  const button = (label, cls, onclick) => {
    const b = h('button', { type: 'button', class: `btn ${cls}`.trim(), onclick }, label);
    buttons.push(b);
    return b;
  };

  const prevBtn = p.page > 0 && !p.sequential
    ? button(S.quizPrev, 'secondary', () => run(() => p.actions.go(answers(), p.page - 1), () => p.onNavigate(p.page - 1)))
    : null;
  const saveBtn = button(S.quizSave, 'secondary', () => run(() => p.actions.save(answers()), () => { say(S.savedMsg); setBusy(false); }));
  const nextBtn = p.nextPage >= 0
    ? button(S.quizNext, '', () => run(() => p.actions.go(answers(), p.nextPage), () => p.onNavigate(p.nextPage)))
    : null;

  const summary = h('p', {}, '');
  const confirmBtn = button(S.confirmSubmit, 'confirm-btn', () => run(
    () => p.actions.finish(answers(), { timeup }),
    () => p.onDone('finished'),
  ));
  const cancelBtn = button(S.cancel, 'secondary', () => { confirm.hidden = true; });
  const confirm = h('div', { class: 'confirm', hidden: true, role: 'group' }, summary, confirmBtn, cancelBtn);
  const finishBtn = button(S.quizFinish, '', async () => {
    if (busy) return;
    setBusy(true);
    say('');
    try {
      const s = await p.actions.loadSummary();
      summary.textContent = S.summaryText.replace('{done}', String(s.answered)).replace('{total}', String(s.total));
    } catch {
      summary.textContent = S.summaryUnknown;
    }
    confirm.hidden = false;
    setBusy(false);
  });

  const timer = p.endTime ? h('p', { class: 'timer' }, '') : null;
  const timeNote = h('p', { class: 'time-up note', hidden: true }, S.timeUp);
  const tick = () => {
    const left = p.endTime - clock.now();
    if (timer) timer.textContent = `${S.timeLeft}: ${formatTimeLeft(left)}`;
    if (left <= 0 && !timeUp) {
      timeUp = true;
      fields.disabled = true;
      timeNote.hidden = false;
      for (const b of [prevBtn, saveBtn, nextBtn]) if (b) b.hidden = true;
      finishBtn.textContent = S.quizSubmitNow;
    }
  };

  const bar = h('div', { class: 'attempt-bar' }, prevBtn, saveBtn, nextBtn, finishBtn);
  const el = h('article', { class: 'course attempt' }, head, timer, timeNote, fields, msg, confirm, bar);
  if (p.endTime) {
    tick();
    let wasConnected = false;
    const handle = clock.every(() => {
      if (el.isConnected) wasConnected = true;
      else if (wasConnected) { clock.stop(handle); return; }
      tick();
    });
  }
  return el;
}
