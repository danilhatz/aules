# Forums (read + reply) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Open a forum from a course, read its topics and posts, and reply with plain text (each reply confirmed), in English and Ukrainian.

**Architecture:** Four thin `api.js` functions over the Moodle forum web services; a pure `src/forum.js` (parsers, thread builder, reply subject/HTML); a DOM module `src/ui/forum.js` (topic list, thread, reply box with in-page confirm); `src/app.js` gets two routes with saved-first loading and a reply write that reuses `guardedWrite` / `sentOnce`. Every string goes into both language files.

**Tech Stack:** Vanilla ES modules, `node:test` + `jsdom`, no new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-13-forums-design.md` (write-safety rules also from `2026-10-13-assignments-design.md`).

## Global Constraints

- Scope: read + reply only. No new topics, edit/delete, attachments on replies, subscriptions, read tracking (no `mod_forum_view_*` calls), avatars.
- Reply is plain text sent as HTML: each non-blank line escaped and wrapped in `<p>`; subject `Re: <parent subject>` (an existing leading `Re:` is not repeated).
- Writes: tap **Send**, then in-page confirm **Yes, send**; single-flight; no automatic retry or replay (`invalidtoken` renews the session and throws `retry`); `network`/`badresponse` after sending -> `unconfirmed` (reload topic, say "could not confirm", keep the draft); every write step refused after sign-out (`auth.epoch()`); draft removed only after confirmed success.
- Drafts: `aules.draft.*` index-based store via `createDrafts`, key `forum.<postId>`; cleared at sign-out (already done by `drafts.clear()`).
- Caches via `createCache`: `forums:<courseId>`, `topics:<forumId>:0`, `posts:<discussionId>` (cleared at sign-out by `cache.clear()`).
- Topic list pages of 20 (`PAGE = 20`); **Load more** only while the last page came back full, and only with fresh data.
- Thread indentation clamps at depth 3; deeper replies show "In reply to {name}".
- Routes: `#/course/<c>/forum/<cmid>` and `#/course/<c>/forum/<cmid>/topic/<id>`; ids are positive integers, otherwise fall back to the course page.
- Message HTML goes through `sanitizeHtml` with `rewriteUrl: (u) => withToken(toWebserviceUrl(u), token)`; attachment links use `withToken`.
- All user-visible text in `src/lang/en.js` and `src/lang/uk.js` (parity test enforces identical keys and `{placeholders}`; Ukrainian values must differ from English and contain Cyrillic).
- Every app-file change needs a `VERSION` bump in `sw.js` and new files in `SHELL`; `npm run lock-shell` at release. Test runner: `npm test`. Never push without the user's explicit OK.
- Commit messages end with: `Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>`

## Review Focus

1. A reply typed with `<`, `&`, quotes or `<script>` must appear literally on Aules, never as markup. Pinned in Task 2 (`replyHtml`).
2. Double-tapping **Yes, send** (or tapping while a request is pending) must send exactly one reply. Pinned in Task 5.
3. A thread with a missing parent, a self-parent or a parent cycle must still show every post exactly once and never loop. Pinned in Task 2 (`buildThread`).
4. A lost connection after **Yes, send** must not claim success or failure: topic reloads, "could not confirm", draft kept. Pinned in Task 5.
5. A deleted post, or a post whose author or message is missing, must not show `null`/`undefined` or throw. Pinned in Tasks 2 and 4.

```js
import { MoodleError } from './api.js';

const num = (v) => (Number.isFinite(Number(v)) ? Number(v) : 0);
const str = (v) => (typeof v === 'string' ? v : '');

export function parseForums(resp) {
  if (!Array.isArray(resp)) throw new MoodleError('badresponse');
  return resp
    .filter((f) => f && Number.isInteger(f.id) && Number.isInteger(f.cmid))
    .map((f) => ({ id: f.id, cmid: f.cmid, name: str(f.name), introHtml: str(f.intro), type: str(f.type) }));
}

export function parseDiscussions(resp) {
  if (!resp || !Array.isArray(resp.discussions)) throw new MoodleError('badresponse');
  return resp.discussions
    .filter((d) => d && Number.isInteger(d.discussion))
    .map((d) => ({
      id: d.discussion,
      title: str(d.name) || str(d.subject),
      author: str(d.userfullname),
      modified: num(d.timemodified),
      replies: num(d.numreplies),
      pinned: d.pinned === true,
      locked: d.locked === true,
      canReply: d.canreply !== false,
    }));
}

export function parsePosts(resp) {
  if (!resp || !Array.isArray(resp.posts)) throw new MoodleError('badresponse');
  return resp.posts
    .filter((p) => p && Number.isInteger(p.id))
    .map((p) => ({
      id: p.id,
      parentId: Number.isInteger(p.parentid) ? p.parentid : 0,
      subject: str(p.subject),
      messageHtml: str(p.message),
      author: str(p.author && p.author.fullname),
      created: num(p.timecreated),
      deleted: p.isdeleted === true,
      canReply: Boolean(p.capabilities && p.capabilities.reply),
      attachments: (Array.isArray(p.attachments) ? p.attachments : [])
        .filter((a) => a && str(a.filename) && str(a.fileurl))
        .map((a) => ({ name: a.filename, url: a.fileurl })),
    }));
}

export const MAX_DEPTH = 3;

// Display order with indentation depth. Every post appears exactly once, whatever the parent links look like.
export function buildThread(posts) {
  const ids = new Set(posts.map((p) => p.id));
  const kids = new Map();
  const roots = [];
  for (const p of posts) {
    if (p.parentId && p.parentId !== p.id && ids.has(p.parentId)) {
      if (!kids.has(p.parentId)) kids.set(p.parentId, []);
      kids.get(p.parentId).push(p);
    } else {
      roots.push(p);
    }
  }
  const byTime = (a, b) => a.created - b.created || a.id - b.id;
  const out = [];
  const seen = new Set();
  const stack = [];
  const push = (list, depth, parentAuthor) => {
    const sorted = list.slice().sort(byTime);
    for (let i = sorted.length - 1; i >= 0; i -= 1) stack.push({ post: sorted[i], depth, parentAuthor });
  };
  push(roots, 0, '');
  while (stack.length) {
    const { post, depth, parentAuthor } = stack.pop();
    if (seen.has(post.id)) continue;
    seen.add(post.id);
    out.push({ post, depth: Math.min(depth, MAX_DEPTH), replyTo: depth > MAX_DEPTH ? parentAuthor : '' });
    push(kids.get(post.id) || [], depth + 1, post.author);
  }
  // Posts that are only linked to each other (a parent cycle) are not reachable from a root: show them flat.
  for (const p of posts.slice().sort(byTime)) {
    if (!seen.has(p.id)) { seen.add(p.id); out.push({ post: p, depth: 0, replyTo: '' }); }
  }
  return out;
}

export function replySubject(parentSubject) {
  const s = String(parentSubject || '').trim();
  return /^re:/i.test(s) ? s : `Re: ${s}`.trim();
}

const esc = (s) => s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;').replace(/'/g, '&#39;');

export function replyHtml(text) {
  return String(text || '')
    .replace(/\r\n?/g, '\n')
    .split('\n')
    .map((l) => l.trim())
    .filter(Boolean)
    .map((l) => `<p>${esc(l)}</p>`)
    .join('');
}

export function canReply(post, discussion = null) {
  return post.canReply && !post.deleted && !(discussion && (discussion.locked || discussion.canReply === false));
}
```

```js
import { h } from './dom.js';
import { STRINGS as S } from '../strings.js';
import { describeError } from '../errors.js';
import { sanitizeHtml } from '../sanitize.js';
import { withToken, toWebserviceUrl } from '../content.js';
import { buildThread, canReply } from '../forum.js';

function errorText(err) {
  const base = describeError(err);
  const detail = err && err.message && err.message !== err.code && !S.errors[err.code] ? ` ${err.message}` : '';
  return base + detail;
}

const when = (ts, locale) => (ts ? new Intl.DateTimeFormat(locale, { dateStyle: 'medium', timeStyle: 'short' }).format(new Date(ts * 1000)) : '');
const backLink = (href, label) => h('a', { class: 'back', href }, '‹ ', label);

function topicRow(p, t) {
  return h('li', { class: 'topic' },
    h('a', { class: 'topic-link', href: `#/course/${p.courseId}/forum/${p.cmid}/topic/${t.id}` }, t.title),
    h('small', { class: 'topic-meta' },
      [t.author, when(t.modified, p.locale), `${S.repliesLabel}: ${t.replies}`].filter(Boolean).join(' · ')),
    t.pinned ? h('span', { class: 'chip' }, S.pinnedLabel) : null,
    t.locked ? h('span', { class: 'chip' }, S.lockedLabel) : null);
}

export function renderForum(p) {
  const rewriteUrl = (u) => withToken(toWebserviceUrl(u), p.token);
  const intro = h('div', { class: 'html intro' });
  intro.innerHTML = sanitizeHtml(p.forum.introHtml, { rewriteUrl });
  const list = h('ul', { class: 'topics' }, p.topics.map((t) => topicRow(p, t)));
  const empty = h('p', { class: 'note', hidden: p.topics.length > 0 }, S.noTopics);
  const msg = h('p', { class: 'form-msg', role: 'alert' }, '');
  let more = null;
  if (p.hasMore && p.fresh && !p.offline) {
    more = h('button', {
      type: 'button',
      class: 'btn secondary',
      onclick: async () => {
        more.disabled = true;
        msg.textContent = '';
        try {
          const r = await p.actions.loadMore();
          for (const t of r.topics) list.append(topicRow(p, t));
          empty.hidden = list.children.length > 0;
          if (r.hasMore) more.disabled = false;
          else more.hidden = true;
        } catch (err) {
          if (err && err.code === 'signedout') return;
          msg.textContent = errorText(err);
          more.disabled = false;
        }
      },
    }, S.loadMore);
  }
  return h('article', { class: 'course forum' },
    h('header', { class: 'bar' }, backLink(`#/course/${p.courseId}`, S.backToCourse), h('h2', {}, p.forum.name)),
    ...(p.offline ? [h('p', { class: 'banner' }, S.offline)] : []),
    intro, list, empty, more, msg);
}

export function renderTopic(p) {
  const rewriteUrl = (u) => withToken(toWebserviceUrl(u), p.token);
  const flashText = { sent: S.replySent, unknown: S.unconfirmed }[p.flash] || '';
  const replyAllowed = p.fresh && !p.offline;
  let busy = false;
  const locks = [];
  const setBusy = (b) => { busy = b; for (const x of locks) x.disabled = b; };

  function replyBlock(post) {
    const area = h('textarea', { class: 'reply-text', rows: 4, 'aria-label': S.yourReply });
    area.value = p.draftOf(post.id) || '';
    area.addEventListener('input', () => p.onDraft(post.id, area.value));
    const msg = h('p', { class: 'form-msg', role: 'alert' }, '');
    const yes = h('button', {
      type: 'button',
      class: 'btn confirm-btn',
      onclick: async () => {
        if (busy) return;
        setBusy(true);
        msg.textContent = '';
        try {
          await p.actions.send(post, area.value);
          p.onDone('sent');
        } catch (err) {
          if (err && err.code === 'signedout') return;
          if (err && err.code === 'unconfirmed') { p.onDone('unknown'); return; }
          msg.textContent = errorText(err);
          setBusy(false);
        }
      },
    }, S.confirmSendYes);
    const cancel = h('button', { type: 'button', class: 'btn secondary', onclick: () => { confirm.hidden = true; } }, S.cancel);
    const confirm = h('div', { class: 'confirm', hidden: true, role: 'group' }, h('p', {}, S.confirmReplyText), yes, cancel);
    const send = h('button', {
      type: 'button',
      class: 'btn',
      onclick: () => {
        if (busy) return;
        if (!area.value.trim()) { msg.textContent = S.replyEmpty; return; }
        msg.textContent = '';
        confirm.hidden = false;
      },
    }, S.sendReply);
    locks.push(area, send, yes, cancel);
    return h('div', { class: 'reply-box', hidden: true }, area, send, confirm, msg);
  }

  function postEl({ post, depth, replyTo }) {
    const body = h('div', { class: 'html message' });
    if (!post.deleted) body.innerHTML = sanitizeHtml(post.messageHtml, { rewriteUrl });
    const showSubject = post.subject && !/^re:/i.test(post.subject) && post.subject !== p.title;
    const el = h('article', { class: `post depth-${depth}`, 'data-id': String(post.id) },
      h('header', { class: 'post-head' },
        h('strong', {}, post.author),
        post.created ? h('small', { class: 'muted' }, ` ${when(post.created, p.locale)}`) : null),
      showSubject ? h('h4', {}, post.subject) : null,
      replyTo ? h('small', { class: 'muted' }, S.inReplyTo.replace('{name}', replyTo)) : null,
      post.deleted ? h('p', { class: 'note' }, S.postRemoved) : body,
      !post.deleted && post.attachments.length
        ? h('ul', { class: 'links' }, post.attachments.map((a) => h('li', {},
          h('a', { href: withToken(a.url, p.token), target: '_blank', rel: 'noopener noreferrer' }, a.name))))
        : null);
    if (replyAllowed && canReply(post, p.discussion)) {
      const box = replyBlock(post);
      const toggle = h('button', { type: 'button', class: 'link reply-btn', onclick: () => { box.hidden = !box.hidden; } }, S.reply);
      locks.push(toggle);
      el.append(toggle, box);
    }
    return el;
  }

  return h('article', { class: 'course topic' },
```
